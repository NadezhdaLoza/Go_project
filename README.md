# Go-project

Микросервисная система учета документов (доверенностей), реализованная на языке программирования Go с использованием чистой архитектуры. Проект включает в себя несколько независимых сервисов (товары, организации, сотрудники, доверенности), взаимодействующих через HTTP API.

## Технологии

*   **Language:** Go (Golang)
*   **Architecture:** Microservices, Clean Architecture (Domain, Service, Repository, Transport layers)
*   **Database:** PostgreSQL
*   **Web Framework/Libraries:** net/http, Gorilla Mux (routing), Go-Kit (endpoints/transport), Grequests (HTTP client for inter-service communication)
*   **Frontend:** HTML/CSS/JS (Server-side rendering via html/template), Materialize CSS
*   **Testing:** Postman

## Архитектура проекта

Проект разделен на микросервисы, каждый из которых имеет собственную структуру папок:

```text
project/
├── services/
│   ├── base/          # Общие утилиты (логирование, подключение к БД, декодирование JSON)
│   ├── product/       # Микросервис товаров
│   │   ├── backend/   # Серверная часть (API)
│   │   │   ├── cmd/   # Точка входа (main.go)
│   │   │   ├── domain/# Сущности (structs)
│   │   │   ├── dto/   # Data Transfer Objects (запросы/ответы)
│   │   │   ├── repo/  # Интерфейсы репозиториев
│   │   │   ├── implementation/ # Реализация репозиториев и сервисов
│   │   │   └── transport/ # HTTP обработчики и эндпоинты
│   │   ── frontend/  # Клиентская часть (HTML шаблоны, JS, обработчики страниц)
│   ├── organization/  # Микросервис организаций
│   ├── employee/      # Микросервис сотрудников
│   ├── customer/      # Микросервис контрагентов
│   ├── account/       # Микросервис счетов
│   └── proxy/         # Микросервис доверенностей (основной документ)
├── sql/               # SQL скрипты для создания таблиц
├── static/            # Глобальные статические ресурсы (css, js)
└── go.mod             # Модуль Go
```

## Установка и запуск
# Предварительные требования
- Установленный Go 1.16+
- Запущенный локальный сервер PostgreSQL (порт 5432)


# Шаги запуска
1. Клонируйте репозиторий:
git clone [URL_РЕПОЗИТОРИЯ]
cd [ИМЯ_ПАПКИ_ПРОЕКТА]
2. Скачайте зависимости:
go mod tidy
3. Инициализируйте базу данных:
Выполните SQL-скрипты из папки /sql/create_tables.sql в вашей СУБД PostgreSQL.
4. Настройте переменные окружения (опционально):
Создайте файл .env в корне проекта, чтобы задать адреса хостов и порты, либо используйте значения по умолчанию (localhost).
5. Запуск сервисов:
Так как это микросервисы, их нужно запускать в отдельных терминалах.
6. Доступ к приложению:
Откройте браузер и перейдите по адресу http://localhost (или http://localhost:80). Прокси-сервер перенаправит запросы к нужным микросервисам.
